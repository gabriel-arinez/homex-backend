# F07.5 — DB-06: catálogo operativo real

## Contrato de entrada

La única entrada soportada es JSON comercial con `schema_version: 1`; el ejemplo
normativo está en `docs/catalogo/contrato_importacion_v1.json`. El JSONL NER de
sillas no es un catálogo comercial y se rechaza explícitamente.

## Ejecución

```bash
uv run python manage.py importar_catalogo ruta/catalogo.json --actor-id ID
uv run python manage.py importar_catalogo ruta/catalogo.json --actor-id ID --dry-run
```

La carga se ejecuta de forma atómica. Un producto nace con stock cero y su
existencia inicial se registra mediante un único movimiento `CARGA_INICIAL`.
Repetir el mismo catálogo no duplica productos ni carga stock nuevamente.
