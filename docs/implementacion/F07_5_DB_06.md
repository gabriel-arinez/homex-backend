# F07.5 — DB-06: catálogo operativo real

## Estado

**Cierre local verificado.**

La implementación de F07.5 supera los gates locales de PostgreSQL,
concurrencia, migraciones, lint, formato, Django y OpenAPI.

La carga real del catálogo permanece bloqueada hasta recibir los datos
comerciales reales de HOMEX.

## Objetivo

Implementar un mecanismo controlado para cargar el catálogo comercial real sin:

- inventar información;
- utilizar el dataset NER como catálogo;
- modificar stock directamente;
- duplicar cargas iniciales;
- aceptar silenciosamente fichas incompletas;
- considerar idempotente un SKU con información comercial diferente.

## Formato soportado

La única entrada aceptada es:

**JSON comercial con `schema_version: 1`.**

Archivo normativo:

`docs/catalogo/contrato_importacion_v1.json`

El dataset JSONL utilizado para entrenamiento NER no constituye un catálogo
comercial y se rechaza explícitamente.
