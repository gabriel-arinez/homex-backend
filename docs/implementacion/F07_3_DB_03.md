# F07.3 — DB-03: aprobación, pedidos, stock y OT

La aprobación se ejecuta mediante `transaction.atomic()` y `SELECT FOR UPDATE`
sobre la proforma. Django autoriza y cambia el estado; PostgreSQL crea el pedido,
las ventas, actualiza stock y crea la OT. Python no duplica esos efectos.

Se añadieron los endpoints de aprobación, lectura/cancelación de pedidos y lectura
de órdenes de trabajo. Las pruebas PostgreSQL cubren aprobación, rollback por
stock insuficiente, VENTA, OT y reversa única al cancelar.

Validación local: suite PostgreSQL, concurrencia, checks, migraciones y OpenAPI.
El cierre formal requiere CI remoto verde del commit de esta fase.
